# ZIMWI 👹

**A USSD + SMS debt ledger for Tanzanian shops, with a playful ogre that chases what customers owe.**

Built with [Kiro](https://kiro.dev) for **Kiroween 2026** (Resurrection category): bringing USSD and SMS, the "dead" tech that still runs East Africa, back to life.

> 🚧 Work in progress. The build started on Oct 30, 2026.
